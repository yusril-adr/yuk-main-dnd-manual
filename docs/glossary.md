# Kamus istilah

| Istilah | Artinya |
| --- | --- |
| **Guild** | Komunitas pemain YukMainDnD |
| **Guildmate** | Sesama anggota guild |
| **Quest** / **Story** | Satu sesi atau rangkaian sesi permainan. Di halaman publik disebut Quest; di Dashboard disebut Story. |
| **Oneshot** | Quest yang selesai dalam satu sesi |
| **Campaign** | Quest panjang yang berlanjut dalam beberapa sesi |
| **Dungeon Master (DM)** | Pemandu cerita yang menjalankan Quest |
| **Hero** / **Player** | Pemain yang ikut dalam Quest |
| **Party** | Kelompok petualang yang bergabung dalam satu Quest |
| **Viewer** | Anggota party yang ikut sebagai penonton dan tidak menerima hadiah |
| **Registered** / **Enlisted** | Sudah mendaftar di party, belum ditentukan hadir atau tidak |
| **Attended** | Ditandai hadir saat Quest diselesaikan, dan menerima hadiah |
| **Player slots** / **Max Members** | Jumlah pemain yang dihadiahi saat Quest selesai. Anggota lain tetap boleh ikut sebagai penonton. |
| **EXP** / **XP** | Poin pengalaman. Ada dua jenis: EXP pemain (**Player EXP**) dan EXP Dungeon Master (**DM EXP**). |
| **Gold** / **GP** (Gold Pieces) | Mata uang guild |
| **Legends** | Tiga pemain dan tiga DM dengan tambahan EXP terbanyak dalam satu bulan |
| **Kartu petualang** | Halaman profil publik seorang Guildmate, yang bisa dicetak |
| **Quest Log** | Daftar Quest yang pernah diikuti atau dipimpin seseorang |
| **Game system** | Aturan permainan yang dipakai, misalnya "DnD 5e 2014" |
| **Online** / **Offline** | Quest dimainkan lewat internet atau bertemu langsung |
| **Draft**, **Published**, **Completed**, **Cancelled**, **Archived** | Status Quest. Lihat [Perjalanan sebuah Quest](dungeon-master/story.md#perjalanan-sebuah-quest). |
| **Recruiting** | Label untuk Quest yang sedang buka (status Published) |
| **Read-aloud text** | Kotak teks dalam cerita Quest yang dibacakan DM ke pemain |
| **Role** | Peran di aplikasi, misalnya **Player** atau **Dungeon Master**. Role menentukan menu yang kamu lihat. Satu akun bisa punya beberapa role, tapi hanya satu yang aktif. |
| **Master** | Kelompok menu Dungeon Master di Dashboard, berisi **Stories** |
| **Board** | Kelompok menu pemain di Dashboard (Stories/My Stories, Events, Goods) |
| **Balances** (Saldo) | Riwayat dan jumlah EXP serta Gold seseorang |
